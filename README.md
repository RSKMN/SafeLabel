# SafeLabel 🍴🛡️

SafeLabel is an AI-powered food label assistant that:
- Extracts product ingredients from uploaded images using OCR (offline)
- Matches ingredients with a searchable database
- Answers safety/ingredient-related questions using LLMs (Groq)
